# Muhandislik fanlari amaliy mashg‘ulotlar platformasi

GitHub Pages uchun tayyor statik platforma. Backend kerak emas, ma’lumotlar brauzer `localStorage` xotirasida saqlanadi.

## Yangilangan imkoniyatlar
- Professional dashboard dizayni
- Chap menyu pastida qizil **Chiqish** tugmasi
- 30 ta fan
- 30 ta amaliy topshiriq
- 30 ta laboratoriya ishi
- 50 ta o‘qituvchi
- 50 ta talaba
- Admin, o‘qituvchi va talaba panellari
- Qidiruv, hisobot, baholash va monitoring

## Demo loginlar
- Admin: `admin` / `admin123`
- O‘qituvchi: `teacher1` / `teacher123`
- Talaba: `student1` / `student123`

## GitHub Pagesga qo‘yish
1. GitHub’da yangi repository oching.
2. `index.html`, `style.css`, `app.js`, `README.md` fayllarini yuklang.
3. Repository → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`, folder: `/root`.
6. Save bosing.
7. 1-2 daqiqadan keyin Pages havolasi ochiladi.

> Eslatma: Eski versiya brauzer xotirasida qolgan bo‘lsa, yangi versiya avtomatik qayta demo ma’lumotlarni yaratadi.
